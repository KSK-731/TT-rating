1. 鍵の設定 未設定

鍵を設定する・作り直す
  1. GitHub の「新しい鍵」画面を開く（GitHub にログインした状態で開きます）。
  2. Token name（名前）：卓球レーティング管理 など、分かる名前を入れます。
  3. Expiration（期限）：いちばん長い期間（1年）を選びます。期限が来たら、この手順で作り直します。
  4. Repository access：Only select repositories を選び、TT-rating だけを選びます。
  5. Permissions（権限）：Contents を Read and write、Actions を Read-only にします。「Add permissions」ボタンがある画面では、そこから Contents と Actions を選びます。ほかはそのままで構いません。
  6. いちばん下の Generate token を押し、表示された github_pat_ で始まる文字をコピーします（この画面を閉じると二度と表示されません）。
  7. 下の欄に貼り付けて「保存して確認」を押します。
リポジトリの持ち主ではない人（引き継いだ人など）の場合

上の方法の鍵は、自分が持ち主のリポジトリにしか使えません。招待されて編集している場合は、次の「従来の鍵」を作ります。

  1. GitHub の「従来の鍵」画面を開く（名前と権限が入った状態で開きます）。
  2. Expiration（期限）：Custom を選び、1年後の日付にします。
  3. Select scopes：public_repo にだけチェックが入っていることを確かめます。
  4. いちばん下の Generate token を押し、表示された ghp_ で始まる文字をコピーして、下の欄に貼り付けます。

鍵はこの端末（このブラウザ）の中にだけ保存され、公開ページやほかの人には送られません。端末をなくしたときは、GitHub の 鍵の一覧 でこの鍵を削除（Delete）してください。

6. 学校の一覧

・名前を直す：打ち間違いを直します。teams.csv と、その学校のすべての試合の名前がまとめて変わります。
・旧校名を登録：校名変更や略し方の違いを登録します（例：「堺」→ 市立堺）。過去の試合はそのままで、同じ学校として数えます。
・消す：試合が1つもない学校だけ消せます。
